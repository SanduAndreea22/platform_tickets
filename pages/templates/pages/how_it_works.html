Demo guide

How this project works

TicketPlatform is a portfolio/demo project built to practice full-stack Django — event booking, Stripe payments, PDF tickets with QR codes and role-based accounts. It's live so you can try the real flow end-to-end.

Payments are in test mode

Stripe's test mode is used — no real card is charged and no real money moves. At checkout, use a test card:

  • Card number: 4242 4242 4242 4242
  • Expiry date: any future date (e.g. 12/34)
  • CVC: any 3 digits

You'll get a real PDF ticket with a QR code afterwards — that part works exactly like it would in production.

The contact form is not actively monitored

Messages sent through the contact page are saved to the database, but there is no support team on the other end — this is a demo, not a live business. Feel free to test the form, just don't expect a reply.

Why this exists

Built as a learning project to practice real-world features — reservations with stock management, Stripe payment intents and webhooks, PDF/QR generation, and role-based access for organizers and participants. Feedback and bug reports are welcome through the contact form.
