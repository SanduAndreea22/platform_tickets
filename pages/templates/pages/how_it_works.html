⭐ About This Project

TicketPlatform is a portfolio/demo project built to practice full-stack Django development — event booking, Stripe payments, PDF ticket generation with QR codes, and role-based accounts. It's live so you can try the real flow end-to-end, but a few things work differently than on a real ticketing site.

💳 Payments are in test mode

This project uses Stripe's test mode — no real card is charged and no real money moves. To try the checkout flow, use one of Stripe's test cards, for example:

  • Card number: 4242 4242 4242 4242
  • Expiry date: any future date (e.g. 12/34)
  • CVC: any 3 digits

You'll get a real PDF ticket with a QR code afterwards — that part works exactly like it would in production.

💬 The contact form is not actively monitored

Messages sent through the contact page are saved to the database, but there is no support team on the other end — this is a demo project, not a live business. Feel free to test the form, just don't expect a reply.

🧑‍💻 Why this exists

This platform was built as a learning project to practice real-world features — reservations with stock management, Stripe payment intents and webhooks, PDF/QR generation, and role-based access for organizers and participants. Feedback and bug reports are always welcome through the contact form above.
